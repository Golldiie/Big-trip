# Big trip

Сервис для планирования путешествий

## Стек

- HTML
- CSS
- JavaScript
- Webpack

## Возможности

- просмотр точек маршрута и подробной информации о поездке;
- создание, редактирование и удаление точек маршрута;
- выбор направления и дополнительных опций для каждой точки;
- фильтрация точек маршрута по периоду поездки;
- сортировка точек маршрута по дате, длительности и стоимости;
- автоматический расчёт общей стоимости поездки;
- автоматическое формирование маршрута и дат поездки;
- отображение состояния загрузки и обработки операций;
- уведомление пользователя об ошибках при работе с сервером.

## Запуск

npm install
npm start
